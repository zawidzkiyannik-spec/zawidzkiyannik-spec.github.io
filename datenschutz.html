Es werden keine Daten verkauft, für Werbung genutzt oder an Dritte weitergegeben. Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Die Verbindung lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
